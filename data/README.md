# data/

Raw market data lives here and is **never committed** (files are several GB).

Sample NASDAQ TotalView-ITCH 5.0 files are published at
<https://emi.nasdaq.com/ITCH/Nasdaq%20ITCH/>, for example `01302019.NASDAQ_ITCH50.gz`.
Download one, decompress it into this folder, and point the tools at it.
